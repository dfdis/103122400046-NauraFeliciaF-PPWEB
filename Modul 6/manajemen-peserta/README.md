
# Aplikasi Manajemen Peserta Praktikum

Aplikasi ini dibuat menggunakan React, JavaScript,
dan Vite untuk mengelola peserta praktikum.

## Fitur
- Menambah peserta
- Mengubah data peserta
- Menghapus peserta
- Mengubah status kehadiran
- Mencari peserta berdasarkan nama atau NIM
- Memfilter peserta berdasarkan kelas
- Menampilkan ringkasan peserta

## Cara Menjalankan

1. Pastikan Node.js sudah terpasang.
2. Buka terminal di folder proyek.
3. Jalankan perintah:

   npm install

4. Jalankan aplikasi:

   npm run dev

5. Buka alamat lokal yang muncul di terminal.

## Pengujian Build

Jalankan perintah berikut:

npm run build
